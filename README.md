# VoiceOver Studio

Aplikasi web voice over berbasis Gemini TTS, by: Saiful Arif. Berjalan penuh di browser, tanpa server dan tanpa login.

Buka lewat GitHub Pages, lalu isi API key Gemini di menu Setelan. Key hanya disimpan di browser Anda.
Panduan lengkap ada di `PANDUAN.md`. Setiap kali `index.html` berubah, naikkan `VERSION` di `sw.js`.
