Ekspor

Bedah YouTube

Tempel URL channel atau video YouTube. Aplikasi mengambil daftar video, membuat transkrip lengkap dengan waktu (SRT) lewat Gemini, lalu menganalisis topik dan menyusun ide topik baru. Semua hasil bisa diunduh.

Key YouTube Data API

Dipakai untuk mengambil daftar video channel dan playlist. Gratis, kuota 10.000 unit per hari (satu channel 25 video sekitar 5 unit). Disimpan hanya di browser ini.
Cara mendapatkan key (5 langkah, sekitar 3 menit)
  1. Buka console.cloud.google.com/projectcreate, masuk dengan akun Google, beri nama proyek bebas (mis. "bedah-youtube"), lalu klik Create. Sudah punya proyek? Pakai saja.
  2. Buka halaman YouTube Data API v3, pastikan proyek yang dipilih di bagian atas sudah benar, lalu klik Enable.
  3. Buka halaman Credentials, klik Create credentials, pilih API key. Salin key yang muncul (diawali AIza).
  4. Disarankan: klik Edit API key, di API restrictions pilih Restrict key, centang YouTube Data API v3, lalu Save. Dengan begitu key tidak bisa dipakai untuk layanan lain jika bocor.
  5. Tempel key di kolom atas, klik Simpan, lalu Uji key. Jika muncul "Key valid", langsung ambil data channel di bawah.
Sudah punya key Gemini dari AI Studio? Key itu dibuat di sebuah proyek Google Cloud. Jika Anda mengaktifkan YouTube Data API v3 di proyek yang sama (langkah 2), key itu bisa dipakai di sini juga. Kalau muncul pesan "belum diaktifkan", berarti langkah 2 belum dilakukan di proyek yang tepat.

1. Sumber

Didukung: @handle, /channel/UC..., /user/..., /c/..., playlist, watch, youtu.be, shorts. URL channel dan playlist butuh Key YouTube Data API (kolom di atas). URL video tunggal tetap jalan tanpa key, tetapi judul dan statistik tidak terisi.

2. Pilih video

Transkrip dan analisis memakai kuota Gemini (video dibaca langsung dari YouTube). Hanya video publik yang bisa dibaca. Paket gratis Google membatasi total durasi video YouTube per hari, jadi mulai dari beberapa video dulu.

3. Ide topik dan pola channel

Dibuat dari judul, statistik, dan hasil analisis video yang sudah dibedah. Semakin banyak video yang dibedah, semakin tajam hasilnya.

Ambil API key
Saat sebuah key kehabisan kuota atau ditolak, aplikasi otomatis memakai key berikutnya dan kembali memutar ke awal. Key yang habis dicoba lagi setelah masa tunggunya selesai (kuota per menit sekitar 1 menit, kuota harian reset sekitar pukul 14:00 WIB). Tempel beberapa key sekaligus (satu per baris) juga bisa. Kuota dihitung per proyek Google Cloud, jadi buat key dari proyek yang berbeda; key dari proyek yang sama berbagi kuota.

Aplikasi (PWA)

Chrome atau Edge di Windows dan Android: tombol Pasang aplikasi, atau menu titik tiga lalu Instal. iPhone atau iPad (Safari): tombol Bagikan lalu Tambahkan ke Layar Utama. Setelah terpasang, aplikasi bisa dibuka offline untuk menulis naskah, mengedit audio, dan melihat Pustaka; generate suara tetap butuh internet.

Kualitas audio

Buang offset DC, letupan sesaat, sunyi di ujung potongan, samakan volume antar bagian, dan ulangi sendiri bagian yang masih kresek.
Instruksi gaya dikirim terpisah dari naskah. Kalau masih terdengar dibacakan, aplikasi mengulang dengan format lebih ketat, lalu tanpa gaya sebagai pilihan terakhir.
Lebih rendah membuat suara lebih stabil dan sedikit artefak, tetapi ekspresi sedikit datar. 0,8 adalah titik tengah yang aman. Kalau model menolak pengaturan ini, aplikasi mengabaikannya sendiri.
